# Phase 3B — private question-level grading (#1371)

Stacked on #1376 at 9f8805a. All prerequisite PRs #1372–#1376 remain draft.

## Implementation and scope

- Additive private ExamGradeRevision table: full ordered question marks, explicit null for ungraded, computed completeness/total, assignment revision and exact variant hash, actor and timestamp, append-only revision history. Composite FK to the current assignment prevents paper reassignment after any saved draft (including all-null drafts). No reset or overwrite. A controlled correction workflow for wrong-paper assignments after grading is deferred.
- DB trigger checks exact assignment, variant mode, active offering and eligible student, sequential revision, exact ordered question IDs/maxima, finite bounded marks and total/completeness. It rejects inconsistent supplied totals and calculates the persisted total. Unique key prevents concurrent revisions; RLS, private schema privileges and verifier protect Data API access. DB owner/superuser operations remain outside application authorization.
- Existing Phase 2B trusted assignment and scheme hash resolution reused; assigned lecturer/co-lecturer with live scoped grant can save, authorized scoped reviewer can read. Archived unchanged schemes remain gradeable for confirmed assignments. Authoritative maxima are server-derived; every question must be included exactly once in a full replacement. Null/missing is never zero. No total or CLO evidence for incomplete grades. No-op save retains current revision; stale draft/assignment revision rejects. Transactions remain serializable.
- Existing isolated workspace activation boundary unchanged. Protected no-store endpoints /grade and /grade/save. Staff markbook shows actual paper, question labels, maxima, CLO/evidence labels, live preview, saved total, revision, incomplete/complete status. Student selection locked while locally edited; explicit save/discard, browser unload warning. Switching outer offering/exam or other workspace mutations can discard unsaved local edits; dedicated route-level navigation/dirty guard and browser acceptance remain outstanding.
- Canonical AssessmentResult, release/publication, finalization, correction and CLO reporting untouched. No grade weights or evidence aggregates are written. Phase 3C must design variant-aware release and preserve the Phase 3A interlock; do not activate real exams until then.
