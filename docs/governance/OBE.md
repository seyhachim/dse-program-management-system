# Outcome-based education (OBE)

Status: proposed implementation guidance; institutional particulars pending verification. See [constitution](CONSTITUTION.md) and [references](REFERENCES.md).

- Start with stakeholder-informed programme learning outcomes (PLOs), then measurable course learning outcomes (CLOs). Preserve identifiers and exact approved versions.
- Support explicit CLO–PLO and competency alignment; mapping strength, cognitive/affective/psychomotor level and thresholds must follow approved programme policy. Do not assume one taxonomy or one fixed number of CLOs.
- Course specifications should trace outcomes to weekly learning activities, teaching approaches, assessment instruments and assessment criteria/questions as appropriate.
- Student learning time (SLT) should reconcile against the approved credit and contact/self-study/assessment allocation. Distinguish teaching, assessment and combined sessions; weeks need not all contain assessments. Verify institutional credit conversions and approved exceptions before enforcing them.
- Separate local grade weights from direct CLO evidence. Supporting mappings are not automatically scored evidence. No evidence is not zero attainment.
- Report attainment only using the documented approved method, with coverage, eligible population, exclusions, policy version and evidence inputs. Do not infer PLO attainment from course grade or mapping alone.
- Bind offerings and results to the correct approved course-spec and curriculum version. Do not reinterpret prior cohorts when curriculum or mapping changes.
- Provide review, moderation, improvement actions and subsequent evaluation.

Developer tests: version isolation, mapping ownership, invalid references, unmapped grade components, missing and zero marks, SLT validation, aggregation boundaries, reproducible exports, authorization. Existing context: [assessment separation](../assessment-grade-clo-separation.md); #255, #1354, #1280. Verify current implementation before coding.
